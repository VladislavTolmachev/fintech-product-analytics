# Fintech Product Analytics

This repository is a portfolio case study about credit-card activation and retention using synthetic data.

The full project is maintained on the `project-preview` branch while the default `main` branch remains a minimal landing page.

- [Open project preview](https://github.com/VladislavTolmachev/fintech-product-analytics/tree/project-preview)
- Data is synthetic; it does not represent Plata or any real financial institution.
- SQL analyses cover funnel conversion, activation, time to first transaction, cohort retention, segmentation, and conversion metrics.

SQL execution in PostgreSQL and final findings are still pending validation.
